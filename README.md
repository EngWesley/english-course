# 🇺🇸 Curso de Inglês A2 → B2/C1

Plataforma personalizada de estudos de inglês para atingir o nível B2/C1 em ~9 meses com 2h30/dia de dedicação.

## 🌐 Acesse a plataforma
[engwesley.github.io/english-course](https://engwesley.github.io/english-course)

## 📋 Estrutura do Curso

| Fase | Período | Nível | Meta |
|------|---------|-------|------|
| 1 | Semanas 1-4 | A2 | Consolidar base |
| 2 | Semanas 5-10 | A2→B1 | Comunicação básica |
| 3 | Semanas 11-16 | B1 | Pensar em inglês |
| 4 | Semanas 17-22 | B1→B2 | Contexto profissional |
| 5 | Semanas 23-28 | B2 | Fluência avançada |
| 6 | Semanas 29-36 | B2→C1 | Comunicação acadêmica |

## ⚙️ Como ativar o GitHub Pages
1. Vá em Settings → Pages
2. Source: Deploy from branch
3. Branch: main / (root)
4. Clique Save
5. Aguarde 1-2 minutos e acesse o link gerado

## 🛠️ Tecnologias
- HTML5, CSS3, JavaScript (Vanilla)
- localStorage para persistência de dados
- Zero dependências externas
